# Desktop Buddy 日常对白

此规范来自玩家的对白反馈。可参考相邻 `humanizer/SKILL.md` 排查文章套话，但对白不是文章，不要把每句改成完整陈述或刻意避免真实口头重复。

- 先想清楚两个人正在干什么、谁先说话、他们熟不熟。开场直接说事，通常不先解释自己的性格或交流方式。
- 用具体琐事带动话题：找不到东西、外卖、起晚了、家里的小毛病、路上碰见什么。普通话、短句、口语省略都可以。
- “啊、哎、嗯、呗、诶、呢、啦、哈哈”看人物和情境使用。不要逐句加语气词，不把所有人写成同一种俏皮腔。
- 回应上一句的实际内容。可以追问、插嘴、没听清、跑题、笑一声、突然想不起来；不要每次都工整地“接纳感受—给出建议—升华关系”。
- 新认识的人常是两三句试探，偶尔卡壳、客气、不知道该聊啥。不要上来倾诉私事、互称知己或编造共同回忆。
- 熟人可以省略解释、打趣和商量小事。亲密用相处方式表现，少写“被看见”“有人懂我”“把感受放进考虑”等抽象总结。
- 性格通过选择和反应表现，不要每次说“我习惯先稳住情绪”“我敏感所以会在意小细节”。即使是性格话题，也围绕一件具体小事。
- 允许温柔、伤心和认真，但要有具体起因，不让每通电话都煽情；也不要每段都追求金句或笑话包袱。
- 父母说话和朋友有区别；父母住在另一座城市。来访要考虑路程。时间、季节、天气、活动写成当下事实时，必须有对应筛选条件。
- 角色台词不说“游戏分钟”“友情值”“触发事件”等实现用语。

编辑 JSON/JS 台词时保留标题、ID、`>` 说话人标记、情绪奖励和条件。不要用运行时大批 `replace()` 修补措辞，应直接编辑文本数据。

写完按人物轮流读一遍：下一句接得上吗？现实里会这么说吗？最后一句是在接话，还是在替读者总结这段话的意义？有假大空的收尾就重写整个来回，不只换同义词。

例：

原：`你顺手的一点关心，让我觉得自己也被认真放进了考虑。`

改：`你还记得我不喝冰的啊？` / `上回你拿着杯子捂半天手，我记住了。` / `哈哈，下回我自己烧水。`

原：`我会先稳住心情，再慢慢组织语言。`

改：`我刚才差点回一大段。` / `后来呢？` / `删了，先把饭吃了再说。`
