# 机场与飞行转场

2026-11-02：机场美术与阶梯往返已接入独立预览和季节游戏测试页；正式季节发布尚未完成。最新交接见 `NEXT_AGENT_HANDOFF.md`。

## 用户决定
- 家门到机场沿用公园/商场的条带转场；银白色背景，风格一致的航站楼贴纸图标。
- 机场到四季地图、四季地图回家，都有单独的客机机舱场景，小人坐在机舱内。
- 场景精致、有圆角弧度、有体积感；所有轮廓仍在原生像素格绘制，不用模糊或矢量抗锯齿。
- 航班以一圈气泡选择。目前只有春季农场，其余三个显示问号。

## 文件与预览
- `art/src/concept/airport.py`：342×118 机场大厅、客机机舱；原生 20×28 坐姿人物。
- `airport_terminal`：步行脚底 y=103，售票柜台 x=29..120，自助机 x=143..162，登机口 x=283..295。
- `airport_cabin` → 动态人物（左上 x=153,y=62）→ `airport_cabin_front`：扶手、安全带前景。
- `trip_airport`：复用 `trip_icons.sticker`，32×28 主体+2px贴纸边，既有图标阴影的有限透明度保留。
- `prototype/airport/index.src.html`：独立动画预览。条带、头像跳动、航班菜单、机舱云层移动、暂停。
- `tools/make_airport_preview.py`：输出 `desktop/dist/airport/`，网页 JS 压缩后发布。无游戏源文件公开。
- 预览示例人物不替代玩家造型；正式接入时须由当前玩家造型实时生成。
- 标牌文字独立高分辨率绘制；场景像素只用整数倍最近邻放大。

构建：`PYTHONPATH=tools:art/src/concept python -m pixelkit build art/src/concept/airport.py`
及 `PYTHONPATH=tools python tools/make_airport_preview.py`。
