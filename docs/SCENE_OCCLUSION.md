# 场景遮挡和鼠标命中核查

对照对象为主世界小屋、家门口、公园、码头、商场、朋友家，茵菲谷农舍及田野，草帽湾旅舍、市集、海岸和水下，以及栗尾市街道、码头和事务所。核查包括画布绘制顺序、独立 UI 层、点击与悬停。覆盖头标、画面坐标、角色前后层、摆在室内外的互动模型及相应的区域交互。

## 固定的绘制顺序

| 顺序 | 元素 | 遮挡规则 |
| --- | --- | --- |
| 1 | 天空、远景、中景、地面、建筑背面 | 由地图提供范围和遮罩。背景和远景的透明像素不占互动位置。 |
| 2 | 角色、道具、树、栏杆、摊位、前台 | 世界物件按脚底或落地线判前后。柜台可挡腿，床被可挡身体，浴室按隐私要求用遮罩。把桌后、桌前和能盖住角色的部分登记为各自的层。 |
| 3 | 水面、雨雪、污染、夜色、局部发光 | 水面可盖住入水部分。窗内观看雨雪使用窗洞遮罩。照明与天气作用于场景内容，发光物按透明形状遮住被挡住的区域。 |
| 4 | 头标和足够显眼的操作提示 | 所有地图的任务头标在画面合成后绘制。标记跟着相机和角色，贴近画面左右边缘会保留整张底牌。与左右切区箭头重叠时头标往上让出按钮区域。顶部空间不足或角色已离开画面时隐藏。 |
| 5 | 对白、任务面板、选择器、转场 | 普通飘字只负责显示，鼠标透过。剧情对白、菜单和遮罩优先于世界命中。转场、剧情及主要模态界面使用同一可见性规则屏蔽任务头标。 |

## 已修复和实机验证

| 位置 | 问题 | 验证 |
| --- | --- | --- |
| 草帽湾海棠市集蕾拉妮 | 棚顶比任务图标后绘制时会切掉底牌。原先靠市集局部的绘制顺序来修。现在与其他地图一起在场景合成后绘制。 | 逐像素比较实机场景中的整张图标，覆盖棚顶的像素完整。 |
| 茵菲谷田野和农舍门口 | 头标随天气图层和夜间调色一起变化，贴近画面边缘时可能裁掉半张。 | 夜间大雪、相机边缘、25% 和 50% 与原图像素比对。实机截图还发现左箭头会压住贴边头标，现通过最终界面命中检查验证箭头避让。转场中确认头标隐藏。 |
| 栗尾市街道 | 任务标记原先和 NPC 一起画，后面的树冠、前栏杆、升降梯前层及污染会覆盖或染暗头标。重叠 NPC 原先点中先绘制的角色。 | 街道场景比对头标全像素。用重叠角色验证悬停和点击共用的命中函数选择最后绘制、显示在前的角色。 |
| 家门口阿简 | 上次替换过文字头标，但世界天气、节日道具仍可能后绘制覆盖它。 | 共用最后绘制的头标，复测整个标记的像素和鼠标命中区域。 |

## 轮廓和命中

| 位置 | 共用规则 |
| --- | --- |
| 季节住宅 | 农舍、旅舍、事务所从作画过程导出家具遮罩，保留桌腿、沙发、灶台和窗框的形状。叠放物件按作画先后裁掉被覆盖的部分。动作、菜单和到达点沿用原定义。 |
| 主世界公共设施 | 公园长椅、小摊和卫生间，以及酒吧和商场室内，使用现成的家具精灵遮罩。酒吧两边卡座分别响应。 |
| 茵菲谷 | 农舍大门、粮仓、长成的果树、牲畜和村民按可见精灵命中。牧场栅栏挡住的部分不接收牲畜点击。田地、树坑和脚印调查用地面区域。 |
| 草帽湾 | 海棠市集按最后绘制的可见像素判断摊位、摊主与过路人。柜台挡住的轮廓隐去。岸边旅舍门、更衣室、沙滩椅、淋浴、冲浪架、沙堡、贝壳、鱼和水下任务道具使用同一精灵命中。 |
| 草帽湾镜头 | 合成画布、鼠标、气泡、角色圆环和任务头标共用底部对齐换算。标准昼夜下水维持目前画面高度，换算也支持相机位移和源画布裁切。 |
| 栗尾市 | 树木、栏杆、船、升降机和角色进入同一落地线队列。对挡住主角和任务演员的树木、栏杆沿用淡化。中城集市、糖炒栗子摊、秋千和锦鲤池用原模型轮廓。 |

场景提供 PNG 或原始帧，`sceneTargetAt()` 先按绘制顺序检查原始像素，周围只留一像素容差。完成形状解析后调用 `drawObjectHover()`。不同地图可复用动作和菜单，通过自己的地图坐标指定从哪里走过去。任务头标可绑定同一动作，在最终绘制位置独立命中。

## 后续核查

| 范围 | 当前边界 |
| --- | --- |
| 场景里的区域入口 | 瞭望台、广场和芦苇荡等范围型交互沿用地面区域，部分栗尾市建筑与稀有海洋生物仍用剧本热点。 |
| 室内动画遮挡 | 房屋使用原有床被、浴室、前台和电视动画构图。动态遮罩仍需在每个新增家具姿态里核对。 |
| 气泡与天气 | 气泡使用通用 DOM 组件。窗内降水、屋檐遮罩及户外声传播继续按场景接入核查表完善。 |
