# 场景遮挡和鼠标命中核查

对照对象为主世界小屋、家门口、公园、码头、商场、朋友家，茵菲谷农舍及田野，草帽湾旅舍、市集、海岸和水下，以及栗尾市街道、码头和事务所。核查包括画布绘制顺序、独立 UI 层、点击与悬停。实机复验覆盖头标、界面按钮的位置、重叠角色命中、小屋电视和朋友家家具。其余条目是从代码查到的差异。

## 固定的绘制顺序

| 顺序 | 元素 | 遮挡规则 |
| --- | --- | --- |
| 1 | 天空、远景、中景、地面、建筑背面 | 由地图提供范围和遮罩。背景和远景的透明像素不占互动位置。 |
| 2 | 角色、道具、树、栏杆、摊位、前台 | 世界物件按脚底或落地线判前后。柜台可挡腿，床被可挡身体，浴室按隐私要求用遮罩。把桌后、桌前和能盖住角色的部分登记为各自的层。 |
| 3 | 水面、雨雪、污染、夜色、局部发光 | 水面可盖住入水部分。窗内观看雨雪使用窗洞遮罩。照明与天气作用于场景内容，发光物按透明形状遮住被挡住的区域。 |
| 4 | 头标和足够显眼的操作提示 | 所有地图的任务头标在画面合成后绘制。标记跟着相机和角色，贴近画面左右边缘会保留整张底牌。与左右切区箭头重叠时头标往上让出按钮区域。顶部空间不足或角色已离开画面时隐藏。 |
| 5 | 对白、任务面板、选择器、转场 | 普通飘字只负责显示，鼠标透过。剧情对白、菜单和遮罩优先于世界命中。转场、剧情及主要模态界面使用同一可见性规则屏蔽任务头标。 |

## 已修复和实机验证

| 位置 | 问题 | 验证 |
| --- | --- | --- |
| 草帽湾海棠市集蕾拉妮 | 棚顶比任务图标后绘制时会切掉底牌。原先靠市集局部的绘制顺序来修。现在与其他地图一起在场景合成后绘制。 | 逐像素比较实机场景中的整张图标，覆盖棚顶的像素完整。 |
| 茵菲谷田野和农舍门口 | 头标随天气图层和夜间调色一起变化，贴近画面边缘时可能裁掉半张。 | 夜间大雪、相机边缘、25% 和 50% 与原图像素比对。实机截图还发现左箭头会压住贴边头标，现通过最终界面命中检查验证箭头避让。转场中确认头标隐藏。 |
| 栗尾市街道 | 任务标记原先和 NPC 一起画，后面的树冠、前栏杆、升降梯前层及污染会覆盖或染暗头标。重叠 NPC 原先点中先绘制的角色。 | 街道场景比对头标全像素。用重叠角色验证悬停和点击共用的命中函数选择最后绘制、显示在前的角色。 |
| 家门口阿简 | 上次替换过文字头标，但世界天气、节日道具仍可能后绘制覆盖它。 | 共用最后绘制的头标，复测整个标记的像素和鼠标命中区域。 |

## 其他遮挡关系和接入缺口

| 范围 | 核查到的行为 | 后续统一点 |
| --- | --- | --- |
| 茵菲谷前景和互动 | 地图会先画 `front` 图片，再画路人和主角。作物、动物、NPC 和家具各登记了自己的点击与悬停函数。人物盖在某像素前还是后，取决于调用顺序。 | 先在地形标出落地线，拆开真正的前景和背景。家具点击和高亮共用一个目标解析，避开玻璃、屋顶阴影和透明边缘。 |
| 草帽湾市集和岸边 | 市集按老板、柜台与棚顶、路人及主角排序，老板可以被柜台挡住。鼠标高亮从人物透明形状找目标，市集点击还会走摊位大矩形与任务钩子。同一处可能高亮人物、点击却进入摊位动作。 | 交互表用同一层和透明形状描述玩家看到的目标，柜台和人物各有明确范围。交叉处按实际前后顺序取目标。 |
| 草帽湾水下镜头 | 合成时从底部对齐并随镜头裁剪、扩高。部分鼠标与高亮路径仍按整张源图高度换算。镜头动画期间画面与热点存在不同的 Y 映射。 | 渲染、NPC 气泡、高亮和点击共用一次镜头投影及反投影。测浅水到深水过渡中点鱼、宝箱和海床道具。 |
| 栗尾市室外坡地 | 树与栏杆用落地线排序，前后分割线及淡化跟着主角。其他 NPC 和船、栏杆分别绘制，尚缺按各自落地线排序及针对任务 NPC 的遮挡处理。点角色身体当前仍使用矩形。 | 角色和带遮挡的地物进入同一深度顺序。关键 NPC 需要看得见的靠近位置，只有可见像素进入命中。码头另测船、平台、栏杆和上方过道的两层关系。 |
| 房间内的床、浴室、前台 | 小屋已拆床被和浴缸前沿，朋友家浴室有遮罩，栗尾市前台对坐着工作的阿简单独盖桌板。季节住宅各自拆具并摆头部，遮罩和家具交互范围分别维护。 | 同类家具登记落脚点、座面或床枕、前景遮罩。空闲时、坐下或睡下后、角色从前后经过时分别检查可见像素与点击面。 |
| 屏幕与餐桌 | 小屋电视从屏幕效果扣掉角色剪影，已通过节目切换的遮挡回归。朋友家在人物之前绘制屏幕，家具测试覆盖 60 个浴厕遮罩。部分季节住宅的电视、菜盘与人物在各自钩子里绘制，屏幕是否盖住角色取决于地图顺序。 | 屏幕画面受屏幕区域与人物剪影共同裁切。餐具、菜盘和桌沿各按需要在身体前后绘制。电视、沙发或餐桌跨场景对照。 |
| 对白、菜单和 HUD | 路人气泡不吃鼠标。公园方向按钮是独立 UI。剧情对白和模态菜单需要吞掉鼠标。家门口阿简的头标有同属 NPC 的按钮，其他一些户外头标只有 NPC 身体或附近摊位响应。 | 共用弹层优先级和交互入口。能直接点击的头标须显式指向同一个任务，不能误触旁边的道路、NPC 或店铺。长气泡在边缘且遇上头标时重新验证布局。 |
