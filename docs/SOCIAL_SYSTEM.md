# 社交系统：第一阶段

本轮实现固定人物、关系、共同经历及来家里做客。一起出门、拜访朋友家仍留待下一阶段；性格和喜好尚不赋值。

## 身份与存档

- 世界人物池 200 人，身份、名字、造型固定，男女名字库各 200 个（40 昵称、60 中式、50 日式、50 欧美简中音译）。不同人物不重名；随机造型排除重复搭配。
- 父母保留独立家庭身份。原有测试好友、好感与造型保留；有效的户外交流或酒保聊天才会把新人物加入联系人，单纯路过不会加入。
- 人物、名单、好感、经历、疏远进度、拒绝次数和当前来访保存在原有 `social` 存档字段；无该字段的旧存档可迁移。
- 名单归零移除时归档身份和经历。再次遇见沿用人物，重新建立关系，并追加“再次遇见”。共同经历只来自实际发生的事件。

## 关系边界

| 友情值 | 称谓 |
| --- | --- |
| >90 | 最好的朋友 |
| 60–90 | 挚友 |
| 20–<60 | 朋友 |
| >0–<20 | 面熟 |
| 0 | 移出名单 |

父母始终是家人，不会因冷落/拒绝扣分，不会遗忘或移除。

四个完整游戏日未联系后，每过一个游戏日 -1。关闭期间不推进这项计算。拒接电话（包括六秒超时）、拒绝来访每次 -1，每位朋友每天最多 -2。低于 10 且超过七个游戏日未见会忘记长相；人脉头像用问号，见面/视频恢复。

少数朋友首次低至 5 或以下会尝试告别电话。可坦诚挽回或接受告别。电话仍有两秒对话避让、真实六秒响铃与暂停。

完成联系才增好感：消息 +2、电话/视频/来访结束 +4、再次见面 +1，每人每日此类收益最多 +6。来访机会卡可带来额外关系变化。不同阶段使用各自对话，并保留原有朋友聊天内容；每人每阶段每渠道分别记录已读内容。较亲近的联系人有更短的主动联系间隔。

## 对话显示

主角在下排发言，对方在原日记所在的上排发言，右侧显示实际联系人的像素头像。
首次显示前先让日记退场，再展开对方气泡。回复时两排独立保留；会话结束并留足阅读时间后，先收起对方框，再恢复日记。视频、语音、消息、户外电话统一分流；匿名论坛使用中性头像和明确标识。场景 NPC 头顶小气泡不变。

长台词在小屏向上换行，小屋及需求/时间条不动。来电、睡觉/晕倒、恢复存档会清理旧对话状态；人脉/设置面板优先显示，不露出重叠的朋友气泡。减少动态模式保留功能。

## 来访

通过联系人菜单“来我家”邀请，需在家、清醒、方便招待（8:00–21:00）。按钮点击时重新判断状态；受阻显示具体原因，不静默禁用。成功显示预计到达的游戏分钟数；暂停时提示时间不会推进，并可点击恢复。面熟阶段先多交流，朋友及以上才会登门。也会有亲友主动打电话提出串门，玩家决定是否接待。

约定 → 来到家门 → 走进客厅 → 沙发坐下 → 对话/事件/机会卡 → 告别 → 自行走出。来访途中可取消，已到家可通过同一按钮送客。主角需要自理时不阻塞；困倦、饥饿、睡觉、出门或晕倒会结束本次接待。来访和共同经历写入日记与“经历”。

首批内容：64 段分级聊天、40 段来访聊天、24 个来访事件、40 张来访机会卡（每张两种选择、四个结果）。新增分级聊天供消息、语音、视频和见面使用，不把渠道变体计作新的原创对话。原有电话、视频与文本内容保留。
