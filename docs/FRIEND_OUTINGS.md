# 朋友同行

在家打开「人脉」，点击朋友卡片 →「出门玩」→ 从门口周围弹出的二级像素气泡选择家门口、公园、商场、码头或酒吧；菜单展开时暂停时间，可按 Esc 或点空白取消。朋友约 10–20 分钟后到门口，再一起步行出门。正在家中做客的同一位朋友可以直接转为同行。再次点击该朋友的「结束同行」可以取消未出发的约定，或一起回家。

朋友需为成年、好感至少 20；父母住在外地，只有实际来访时才能一起出门。雷雨时不约户外，酒吧仍遵循日落后营业规则。现有串门、留宿、电话和消息继续使用原来的系统。

## 内容与画面

- 通用同行对白 200 组。
- 家门口、凉亭、湖畔、公园中央、野餐草坪、樱花林、商场、餐厅、影院、码头、酒吧各 100 组，共 1,300 组独立的四句对话。
- 家中串门通用对白从 200 组扩充为 300 组。新增的较熟朋友间吐槽只在好感至少 60 时出现。
- 同行专属机会卡 40 张：家门口 4、公园 12、商场 8、码头 8、酒吧 8。普通机会卡在同行期间停止抽取；回家后恢复。
- 公园长椅左右两座、小摊两只凳子、餐厅同桌两把椅子、影院相邻座位和酒吧空位均使用实际坐姿。餐厅和小摊分别绘制两份食物。
- 朋友的形象始终来自已保存联系人，起步、转向、停步约比主角慢 0.24 秒，步态也略有差异。地图和室内切换后仍是同一个人。

对话分主角和朋友两个框显示。大部分完整聊完的对话增加 1 点好感，沿用社交系统每天共计最多 6 点的普通互动奖励上限；少量处理物品的小对话不加好感。专属机会卡按结果结算。日记、共同经历和头像的绿色好感反馈继续生效。部分话题会带来轻微情绪，具体条件写在数据中，不在运行时凭文本关键词猜测。

## 状态与边界

`friend_outings.js` 独立维护 `waiting → departing → active → returning`。联系人身份、场景、行走、需求、转场和机会卡结果继续复用原系统。

- 等朋友时暂停自主出门，保持正常室内生活；不会同时接待另一个客人。
- 出门中保留自主吃饭、如厕、疲劳回家的逻辑。商场先找餐厅/卫生间，公园先找小摊/公厕。
- 已经碰面的同行好友不再打来电话或视频，排队中的来电也会取消；其他朋友的来电不受影响。
- 朋友在公厕/酒吧卫生间外等候。私人活动、睡眠、远程通话、转场和机会卡期间暂停同行对白。
- 雷雨开始时结束户外活动并回家；商场和酒吧仍可继续。
- 尚未出发就取消不发放出游奖励。未聊完的对话也不发放完整对话奖励。
- 存档只保存联系人 ID、阶段、目的地、时间和话题历史，不保存 Canvas、NPC 缓存或正在计时的对白。读取时在恢复实际场景后校正同行与座位，门口出发中断会重启出发行程。
- 旧存档没有 `social.friendOuting` 时继续独自生活。未修改 EXE 版本号和桌面更新源。

## 验证命令

先从源码重建页面，再对该页面运行验证：

```sh
PYTHONPATH=tools python3 tools/make_demo.py
node desktop/scripts/copy-web.mjs
node tools/check_outing_polish.js http://127.0.0.1:8786/
node tools/check_friend_outings.js http://127.0.0.1:8786/
node tools/check_friend_outing_lifecycle.js http://127.0.0.1:8786/
node tools/check_ui_layout.js http://127.0.0.1:8786/
node tools/check_card_typography.js http://127.0.0.1:8786/
node tools/check_card_result.js http://127.0.0.1:8786/
```

同行验证覆盖真实社交入口、五个目的地、四档面板尺寸、等待与出门、五处公园长椅、小摊座位、三家餐厅、16 部电影、六处酒吧座位、无空座时保持站姿、需求处理、专属卡隔离、奖励不重复、浏览器实际刷新读档和酒吧回家。UI 矩阵另覆盖 25/50/75/100% 的目的地和结束同行面板。机会卡检查遍历当前全部 640 张，而非只检查新增卡。

休息时段邀请普通朋友时，直接由朋友聊天框婉拒，早上/夜间各 12 条自然对白；不扣好感，不再弹营业时间式通知。父母仍按异地探望的原有规则回答。
