# 季节地图必要标准（茵菲谷 / 草帽湾 / 以后的每张地图）

主人 2026-11-06 要求：把做茵菲谷、草帽湾时提过的要求整理成一份硬标准，免得做成半成品。
**任何季节地图的新功能，下面每一条都满足才算做完。** 做不到的条目，要在回复里明说缺了什么。
默认原则：**能套用主世界家里现成的动作、效果、流程，就必须套用**，并且和以前的要求保持一致。
**生活精度要完全完全对标主世界**（主人 2026-11-06）。房子里的家具不能另写一套近似的逻辑，
必须走 `prototype/map-test/season_house.js`：它直接跑主世界的 ACTS / EFFECT / lifeArrive / lifeFinish / activityFrame，
所以时长、需求变化、表情和姿势、头顶气泡、日记、心情、做饭到上桌吃饭、中途去厕所，全都和家里一样。
主世界没有的动作（沙发、尤克里里、淋浴、整理衣柜）在那里按主世界的格式补一条，再接进去。

## 1. 去留：她不会自己离开
- 在季节地图里，她**绝不自己回主世界**，任何情况下都一样，包括需求变红、没憋住要洗澡、累倒、困了想睡觉、饿了想做饭。
  所有“室内动作”（洗澡、睡觉、做饭、吃饭、上厕所……）都必须被地图自己的房子或旅社接住，
  不能走主世界的“先回家”。
- 唯一例外：草帽湾只有夏、秋两季有航班。她在岛上时秋天结束，就说一句理由（“再不回家就没航班了！”），然后坐飞机回家。
- 离开**只有一个入口**：点小人，在圆环里选「离开茵菲谷 / 离开草帽湾」。离开时播放过场，飞机动画 3 秒。
- 需求照料的顺序：先去地图里的房子（农舍 / 旅社 / 更衣室），没有房子就去地图里最近的设施。
  每张地图都要有能满足**六种需求**的地方。
- 正式版（`--release`）也要测：把需求压到红、膀胱压到 0，确认她留在地图里。

## 2. 房子里的家具：和主世界的家一模一样
家具的标准是“像在自己家里一样”，每件家具都必须做到：
- 点击家具：她走过去 → 用**现成的姿势** → 需求上涨 → 涨满后自动结束，不卡住。
- 姿势要和主世界一致，绝不能让小人凭空消失：
  - 马桶、沙发、长椅、餐椅：坐姿（`pose:'sit'`，用 `iy` 把高度对齐座面）。
  - 床：躺下，盖被子，飘 z。
  - 只有主世界里本来就看不见她的地方，才可以隐藏小人，比如浴缸 / 淋浴。
- 效果要套用主世界现成的：
  - **吃饭**：坐在餐桌前，有咀嚼的动作（表情和 bob 交替），冒小碗气泡，**桌上有那盘冒热气的饭菜**，吃完撤掉。
  - **做饭**：灶台有做饭的动画，做完饭端到餐桌上，她再坐过去吃。
  - **睡觉**：zz。**洗澡**：水花。
- **厨房必须有餐桌和椅子**。
- 鼠标悬停时家具要有高亮，和主世界一样。
- 只能看的东西（画、台灯……）点了以后，她走过去说一句话。

## 3. 自主行动：玩家不操作时她自己的生活
- 玩家一段时间不操作，她要自己找事做；玩家一点任何东西，自主计划立即取消。
- 任一需求低于 40 时，不做自己的计划，先照料需求（见第 1 条）。
- 茵菲谷：散步、进屋起居（坐坐、整理、吃东西）、浇水、喂动物 / 摸动物 / 收蛋收奶、偶尔收菜、偶尔摘果。
  **绝不播种，绝不购买。**
- 草帽湾：先去更衣室换泳装，再去海面或水下游泳、坐空着的气垫（过一会儿自己下来）、逛集市、去岸边。
  **绝不摆摊，绝不买卖**；也不去深海远处，那里留给玩家。

## 4. 圆环和点击
- 她的圆环里只放这张地图能做的事：
  - 草帽湾：冲浪 / 取消冲浪 / 下来游泳 / 离开草帽湾。
  - 茵菲谷：回家 / 回房间歇歇 / 离开茵菲谷。
  - 主世界的「回家」一律替换掉。
- NPC 正在使用某样东西（比如坐在气垫上）时，玩家就不能用它。
- NPC 和任务点不能挡住箭头、家具、动物、树的点击和悬停。

## 5. 对话和任务
- **对话只靠点击推进，绝不自动翻页**。新的一句刚出现的 0.3 秒内，点击不算数。
- 有选项的对话，选项必须看得见；由小人自己说出的那句不显示选项，所以要换成对方来问。
- 任务 NPC 出现的时间要宽松（例如 5–22 时），每天的出现用种子随机，接了任务以后就一直在。
- 每个场景都有随机支线任务；任务文本口语化（`.claude/skills/everyday-dialogue`）。

## 6. 机会卡
- 数量要多，按区域分（海上 / 陆地 / 集市 ……），只在合适的地方抽到。
- **只有少数卡影响丢丢币，其中大部分是加钱**，极少数会扣一点点钱。不能每张都动钱。

## 7. 画面
- 新画的图**先给主人看**，点头后再接进游戏。
- 远景、中景、近景按视差分层滚动，陆地和海上都要分层；远山要低，不能被云挡住，也不能盖住近景。
  远处的薄纱 / 雾不能厚到让画面雾蒙蒙的。
- 海里的生物分布均匀，不扎堆；大型鱼只在更深、更远的地方出现。
- 冲浪、坐气垫等新动作：用现成的姿势加道具，脚面、冲浪板和水面要齐平。

## 8. 做完前的检查清单
1. 用 Playwright 跑新功能，每个新动作、新姿势都**截图亲眼看**：小人在不在，姿势对不对，道具在不在。
2. 第 1 条的去留测试（正式版构建，需求压红）。
3. 第 2 条：这个功能在主世界的家里有哪些动作和效果？逐项对照，缺一项就不算做完。
4. 跑 `tools/check_season_game_test.js`、`tools/check_infei_side.js` 等相关测试。
5. 存档、读档后状态正确。
6. 在 `docs/AGENT_LOG.md` 写一条记录，推送，然后把网页预览链接发给主人。
