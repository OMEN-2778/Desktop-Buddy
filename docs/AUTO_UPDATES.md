# 桌面自动更新

`prototype/demo/updates.js` 集中处理更新状态，`index.src.html` 在存档/设置和资源加载完成后启动调度。

- 每次启动检查一次；运行期间每小时检查；从关闭切到开启自动更新时立即检查。
- 休眠或后台定时器错过整点时，回到前台会补检查。全部使用真实时间，独立于游戏倍速和暂停。
- “以后”只推迟到下一轮，不再阻止整个运行期间的检查。
- 检查中的状态阻止并发请求；检查或下载失败最多连续尝试三次，随后等待下一小时，避免反复请求。
- 自动下载完成后，等用户 20 秒未操作、没有菜单/机会卡/通话等交互再更新。切回“只提醒”后，不会因为之前启动过后台下载就自动重启。
- 必须先成功保存游戏，才允许执行原生安装或替换程序。保存失败时保留已下载状态并提示重试。
- 原有 GitHub 与镜像端点、可执行文件签名验证及安装版/便携版更新策略继续保留。

旧版自身的调度逻辑无法被网页修复；旧版需手动检查更新或下载安装新 EXE 一次，此后启用新的启动/每小时调度。

验证：`node tools/check_auto_updates.js` 覆盖启动、小时、开关、提醒延后、并发检查、检查/下载失败重试、下载中关闭自动更新、保存失败阻止重启、正常保存后更新。实际 Windows 编译、签名、发布和 `latest.json` 另由桌面 CI 验证。
