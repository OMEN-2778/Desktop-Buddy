## 踩坑与不要重复做的事
- `IMG.trip` 在boot加载过程中会重建。机场图片的独立Promise可能更早结束；不要在ready回调直接写 `IMG.trip.airport`，会undefined或随后被覆盖。当前在真正调用机场trip前挂图标。
- `cardHolds()` 必须包含对白/飞行；否则背景人物、需求、剧情自主移动继续运行。秋日还要同步 `modalOpen`、Esc、move与自动探索判定，不能只隐藏旧框。
- 旧秋日回归脚本查 `.autumn-panel`；迁移后对白要查 `.story-speech`，信息卡继续查旧类；家门不再直接列秋季，回归通过明确测试工具栏进入。
- 不要把所有发言NPC瞬移到主角身边；现有旧剧本包含画外发言，气泡明确标识。
- `trip()` 的 reduceMotion 分支会直接swap；机舱“两秒”不能借用该分支省掉，飞行采用独立状态机。
- 字体本地有CJK、CI不一定有；静态合并图保留已渲染版本，场景像素最近邻放大，文字独立绘制。
- 场景美术禁止平滑矢量抗锯齿；用户白浅蓝渐变只授权对白UI。圆角用原生像素阶梯，材质用明暗体积。
- 不用大范围rg扫描生成的index.html（内嵌base64会炸输出）。优先搜 `.src.html` 与 `.js`，设 `--max-columns`。
- 普通git push曾因无upstream失败，已设置；共享分支提交前拉取，别覆盖CC更新。
- iPad无法打开历史sandbox文档链接，已通过普通HTTPS发布旧剧情docx/readpage；不再反复给失效本地文档链接。
- 公共仓库只允许构建压缩页面、渲染美术及明确授权文档；不可泄露私有源代码。发布流水线约数分钟，区分本地通过、推送、公共部署完成。
