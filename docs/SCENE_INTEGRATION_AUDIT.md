# 场景接入核查

核查基线为正式构建可到达的主世界、茵菲谷、草帽湾，以及网页内测的栗尾市。各地图用自己的地形、建筑、气候表现和演出内容。通用状态、交互与渲染组件集中维护。表中记录已修复的差异和后续验收。

## 天气和天色优先

| 核查项 | 代码中的差异 | 统一接入方式 |
| --- | --- | --- |
| 当前天气与时间条 | 主世界用 `planDay()`、`weatherAt()`、`updateWeather()` 更新天气，时间条读取 `weather.kind`。草帽湾的降雪由共用 `sceneWeatherKind()` 折算为小雨，时间条和场景消费当地结果。 | 全局天气计划提供原始状态。用场景 ID 和气候配置得到一次当地天气，时间条、画面、环境声、路人作息、对白和机会卡都读当地结果。草帽湾登记「降雪折算为小雨」，茵菲谷保留四季，栗尾市污染和天气分别取值。 |
| 雨雪、雷电、室内外与水下 | 主世界按窗户遮罩绘制雨雪，并有雷雨音效和路人反应。季节地图共用雨雪粒子，草帽湾海岸和市集都绘制当地天气。海岸会按水面裁切，季节地图也有各自的室内入口。 | 场景提供室内外、水线、屋檐与窗户遮罩，由共用天气层决定雨雪可见区域和声音传播。晴、雨、雷雨、雪及强度取自同一次天气解析。统一入口允许场景配置雷雨行为，不影响剧情演员和任务站位。 |
| 日出、日落、夜色与室内灯 | 主世界、茵菲谷复用 `duskState()`、`outdoorNightness()`。草帽湾沿用玫瑰色晚霞，夜色进度共用 `outdoorNightness()`。栗尾市街道和事务所窗景按同一夜色进度渐变。 | 同一次取样提供昼夜相位、晚霞强度、室外暗度与室内暗度。地图登记海岸玫瑰晚霞、污染色调、房间范围与光源等配置。室外、窗内看出去的景色、局部照明使用同一相位。店铺作息仍按地点表配置。 |
| 天气与灯光层级 | 草帽湾的夜间发光物有独立后处理，栗尾市在画面上叠污染层和稀疏风沙。任务头标已统一到场景画面合成之后。 | 给天空、世界前后景、可遮挡天气、夜色、局部发光、交互提示与转场定义固定顺序。地图提交遮罩和光源。验收在晴、雨、黄昏、夜间比较同类按钮和头标的可读性。 |
| 进出地图与读档 | 晚霞有存档种子。草帽湾的天气在正常更新和读档时均从当地气候解析。主世界存档恢复先重算 `weatherAt(sim.t)`。 | 进场和恢复后用同一个存档时间与天气计划解析场景，换区沿用气象过程。剧情锁冻结游戏时钟及天气阶段。预览专用天气覆盖一并作用于时间条、粒子、声效和环境行为。 |

## 其他可统一的接入面

| 接入面 | 已复用或仍存在的分岔 | 下次新增场景时提交的数据 |
| --- | --- | --- |
| 指令、路径和镜头 | 公园、茵菲谷、草帽湾共用左右箭头，季节地图仍各有走路、交互、镜头和自主调度。栗尾市有独立的真实时间手动控制保护，茵菲谷和草帽湾主要用游戏分钟安排自主行为。 | 路网、楼梯、出口、镜头边界。接入同一个玩家指令优先判断、到达回调和取消流程。按屏幕坐标反算游戏坐标，点击和悬停共用同一块热区。 |
| 家具、小摊及支付 | 主世界选物界面已用于电视、厨房和多处摊位。农舍和旅舍通过季节起居桥接播放动作，朋友家和栗尾市部分公共设施仍用独立执行流程。季节摊位与农场通过同一账本记币。 | 互动位置、座面高度、遮挡、动作 ID、当地菜谱与营业时间。使用同一选择器、付款校验和账本，让相同动作共享姿势、道具和日记反馈。 |
| NPC 外观、头顶信息和交互 | NPC 使用现有角色模型，路人气泡和本轮的任务头标已有共用绘制。不同地图仍各自处理成人、儿童、坐姿和水下角色的头顶高度，以及点在标记上时是否命中。 | 角色、作息、任务状态、真实头顶和热区。头标按角色姿势取锚点，同一任务状态驱动头标、可交互性和任务卡。 |
| 任务和演出 | 任务面板、对白组件、锁登记已有共用接口。春夏异步队列和栗尾市导演分别处理走位、黑场、取消和读档续演。 | 任务 ID、目标、状态、演员、走位和对白。复用一条锁定、换人、黑场、续演与结束路径，只有任务脚本指定的动作在锁内推进。 |
| 节日、机会卡与音频 | 共享日历和机会卡入口已存在。草帽湾通过额外包装改节日判定，部分音乐路由由构建脚本插入，茵菲谷环境声音单独计算。 | 按场景登记节日与活动、气候与时段条件、BGM 与环境声表。用同一个日历和音频选择入口，进入室内、换图或演出时按场景配置过渡。 |
| 保存与旧档 | 主存档入口共用。季节模块包装读写并各持进度字段，地图脚本也各自重建目标与室内状态。 | 稳定的地图和任务 ID，显式列出长期状态、迁移和恢复位置，奖励按任务完成事件去重。临时渲染状态由当前时间、场景和活动重建。 |

验收按玩家会遇到的路径走一遍。用同一存档在晴天、雷雨、黄昏和夜间进出小屋、农舍、旅舍和事务所，比较天气条、窗外、地面、环境声与坐卧动作。另做草帽湾降雪折算、进出水面、换图读档、暂停和 25% 缩放；桌面构建使用鼠标。
