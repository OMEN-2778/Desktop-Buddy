# 八卦对白扩充与主客身份修正

本轮保留原有对白，在指定的 55 个对白池分别追加与原数量相同的条目，新增 1024 组交流条目。基础内容为 630 条独立八卦故事、20 条克制的初识小趣事，按消息、电话、视频、关系阶段、性格了解阶段、在家聊天和留宿适配；部分基础故事会用于不同交流方式，不把它们宣称为 1024 个独立故事。

| 白话池 | 原数量 | 现在 |
|---|---:|---:|
| 好友电话专用基础池（含补充） | 100 | 200 |
| 好友视频专用基础池（含补充） | 80 | 160 |
| 发消息基础池 | 12 | 24 |
| 每个友情阶段的公共对白 | 32 | 64 |
| 每种方式的初识对白 | 20 | 40 |
| 家中通用聊天 | 300 | 600 |
| 家中原有串门聊天补充 | 40 | 80 |
| 看电视／吃饭／下雨／下雪，各自 | 20 | 40 |
| 每个季节的主题聊天 | 5 | 10 |
| 每个时段的主题聊天 | 4 | 8 |
| 性格各了解阶段的对白，总计 | 42 | 84 |
| 留宿床边聊天 | 80 | 160 |
| 去朋友家普通聊天 | 50 | 100 |

上表为基础池数量；实际选择还会合并关系和性格池、去重并过滤时段。详细逐池统计见 `prototype/demo/dialogue/gossip_expansion_report.json`。

## 文本在哪里

- `prototype/demo/dialogue/gossip_stories.txt`：630 条基础故事，每行“标题｜分享｜追问｜后续/吐槽”，使用实际 ASCII `|` 分隔。
- `prototype/demo/dialogue/early_gossip.txt`：20 条初识小趣事，避免私人感情打听或突然亲密。
- `prototype/demo/dialogue/gossip_channels.json`：电话、视频、消息额外内容，由构建程序接入原有基础列表。
- `prototype/demo/social_dialogue.json`：电话/视频补充、早期交往、关系阶段、性格阶段、家中各类情境对白。
- `prototype/demo/social_text.json`：关系基础对白和原有串门补充。
- `prototype/demo/home_visit_text.json`：留宿床边聊天。
- `prototype/demo/friend_visit_text.json`：去朋友家的聊天。

`python3 tools/expand_social_gossip.py` 根据故事源生成扩充条目，可重复运行而不再次翻倍。没有修改户外初见、邀请选项、事件叙述或机会卡叙述的数量。

## 身份与标点

一般社交对白 `>` 表示对方，普通行表示主角；朋友家文件相反，`>` 表示主角（客人），无标记表示朋友（房主）。修复了 12 组旧对白的角色反向，不简单替换文字里的“我／你”。新增八卦多为第三人称趣事，不把当前房屋错误当成主角所有。

对白显示使用 `spokenText()` 去掉句末中文句号和单个英文句点，保留问号、感叹号、中英文省略号、版本数字等。日记和说明叙述不经过这个转换，继续保留正常句号。

## 验证

- `node tools/check_gossip_expansion.js`：逐池翻倍统计、基础故事唯一性、实际编译后的池数量、各关系阶段选词、初识保护、对白标点及日记标点。
- `node tools/check_guest_roles_tv_audio.js`：实际做客聊天的说话人路由及电视声音。
- `node tools/check_call_resume.js`：发消息/电话/视频经过洗澡、如厕时暂停并续上。
