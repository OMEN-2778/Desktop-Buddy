宽度全部不超过主角房屋的 342 像素。家具保留原有像素尺寸，没有为塞入小房间而压缩。各层之间有真实楼梯口和连续踏步，楼梯井至少 40 像素，踏步 22 像素，给后续人物上下楼留出空间。

## 预览与进度

这一版用于比较、修改房屋样式。预览人物只作比例参照，不启动拜访、事件、需求恢复或关系互动，也不替任何联系人分配永久房屋。

预览期间暂停真实模拟和来电，自动/手动存档均被拦住；退出后继续原来的地点、时间、需求、好友与活动。较高房屋使用独立画布高度，人物和家具保持同一像素比例。设置、日记、情绪、需求及时间栏跟随布局向上移动，采用 620 毫秒的位移/揭示动画；减少动态模式直接显示最终位置。快速切换会从当前可见位置继续，不累积动画。

夜景表示窗外为夜晚、室内开灯。原版房屋的场景尺寸、寻路、光照、电视和睡眠绘制不受预览画布影响。

## 资源与后续接入

- `art/src/concept/friend_houses.py`：30 份显式房间布局、墙纸与家具绘制；输出背景和前景分层。
- `art/src/concept/friend_furniture.py`：40 款原生尺寸的家具、绿植与设备素材；木框接合、藤编、软包缝线、叶脉与盆沿均独立绘制，按类别复用。
- `prototype/demo/friend_houses.js`：独立预览控制、人物比例、日夜切换和 UI 动画。
- `tools/make_demo.py`：打包日景、夜景、前景，以及房间、家具、入口、座位和门/楼梯连接信息。

正式做客可利用 `rooms`、`entry`、`seats`、`links` 接入寻路和互动。静态检查已验证每间房屋的门/楼梯连接图连通，家具与入口均在边界内，最小户型只有卧室和卫生间。

```sh
PYTHONPATH=tools python3 tools/check_friend_house_plans.py
node tools/check_friend_houses.js http://127.0.0.1:8786/
node tools/check_ui_layout.js http://127.0.0.1:8786/
```

检查覆盖全部户型、四档尺寸、日夜与比例人物、预览暂停/存档隔离、切换/退出、上移动画，以及原有 UI、电视遮挡、留宿和同行流程。

## 配色与可复用搭配

30 种是不同房间结构，不以换颜色充数。每套采用一个织物主色和统一木色：奶油/橡木、灰绿/浅木、蓝灰/浅木、砖红/胡桃木等。家具按户型、楼层、房间和类别的稳定哈希选款，日夜保持同一套家具，不随刷新闪变。`GROUPS` 和 `asset(key, accent, timber)` 可供后续随机房屋生成器复用；本次没有改动正式联系人住址或存档。`furniture[].asset` 记录已选的可替换款式。
