# 宠物外观与动作试作

本次只做素材和独立预览，不接入存档、领养、需求、家具或自主生活。游戏页面不会加载这批图集；预览发布到 `/pets/`。

- `art/src/concept/pets.py`：12 种猫外观、12 个狗品种的确定性像素绘制。32×28 透明图格，脚底锚点 y=25，与主角 20×28 采用同一像素尺度和仓库调色板。
- 猫使用同一几何骨架，仅改变花色；狗改变身长、身体厚度、腿长、头部、耳朵、尾巴。
- 每种猫 25 组动作，每种狗 26 组动作，各提供左右、正面和背面图格。单次过渡与循环动作在 manifest 中标记，预览会重复播放便于检查。
- 共用动作含站立呼吸、眨眼、慢走、小跑、坐下、坐着等、起身、趴下、休息、睡觉、睡醒、吃饭、喝水、嗅闻、张望、舔毛、后腿抓痒、伸懒腰、玩耍、回应、蹭蹭、翻滚、抖身。猫另有踩奶和扑跃；狗另有摇尾、喘气和张嘴叫。
- `tools/make_pet_preview.py`：构建独立的自包含 HTML、透明 PNG 图集和 JSON 清单。加 `--review` 生成带中文标签的总览及离线包（需要本机 CJK 字体）。
- `prototype/pets/index.src.html`：选择品种、动作、方向、播放速度，暂停、单帧、滑动选帧，主角比例参照。
- `tools/check_pet_art.py`：全帧透明度、调色板、边缘裁切、猫骨架一致性、狗轮廓差异和动作非静态检查。

可运行：

```sh
PYTHONPATH=tools python3 tools/make_pet_preview.py --review
PYTHONPATH=tools python3 tools/check_pet_art.py
```

素材原创，使用现有 pixelkit 调色板，无新增第三方美术资产。

## 已确认、留待补充后接入的设定

1. 每个家庭最多一只宠物；电脑和游戏内手机操作气泡增加“领养宠物”。
2. 上方窗口展示每周候选名单：6 只猫、6 只狗，品种和性格随机，每周更换。
3. 领养二次确认：“领养宠物意味着长久的责任，您做好准备了吗？”；“我明白 / 我再考虑考虑”。确认后取名。
4. 日记提示：“感谢您的领养，「宠物名字」大概一天后就会送到您家！”
5. 客厅沙发和电视之间安置自动喂食机，电视右边安置睡垫；本次暂不摆放。
6. 喂食机容量 900 饱食度，每次添粮直接补满；宠物饱腹上限 100，约 30 小时耗尽。
7. 只用两个性格维度：慵懒↔活跃、独立↔黏人。
8. 只用三个需求：饱腹、精力、陪伴。自主行为贴近日常但控制复杂度，扩充配套文本。
9. 用户仍将补充事项，暂不实现全套模块。

## 造型与动作修订

猫的头部改用独立的脸颊、下颌和耳廓轮廓，增加虹膜、短鼻口、胡须根和圆爪趾缝；猫仍共用一套几何模型。虎斑按身体曲面分布弯曲、断续斑纹，三花与玳瑁使用不规则色块，重点色覆盖脸、耳与末端，不再使用均匀直条纹。

狗保留原头部，四肢增加实际厚度和圆爪。侧面躯干与颈肩合并成一个连续遮罩，颈部末端随每帧头部位置计算，修复坐卧、伸展等动作中的头身脱节；卷尾也连接尾根。短腿犬坐下时限制臀部高度，避免沉入地面。

`check_pet_art.py` 新增像素连通性和地面边界检查，用于捕捉头身、四肢、尾巴分离和穿地。图集、总览与离线预览包随本轮一起重新生成。
