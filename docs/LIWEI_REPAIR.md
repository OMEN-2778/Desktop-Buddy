# 栗尾维修记

主线 S14 完成后，既有存档第一次进入新版时开放《栗尾维修记》。任务卡沿用统一任务面板，使用橙粉渐变、像素工具箱和循环火星。在工人街西侧闲置的居民小屋门口找许师傅接任务。帮许师傅送完食堂与洗衣铺的旧单，再修好收音机后，他会留下钥匙。点击小屋即可开摊。来客卡位于场景下部，街坊来往留在街景内。

## 玩法和收支

- 顾客每次带一件物品上门，对应随机分配收音机、车、挂钟、水路或磁带玩法。保留已接委托的随机种子、已修好和已交付状态。局内退出后从该单初始状态重试。日内可完成多个人情单，付费工钱日结一次，延期的付费单保留报酬。
- 自动扫频走三路自动清理与四轮升级。试车通过转动指针做三次校正。挂钟用试敲反馈找齿轮顺序。漏水玩法旋转管向并试流，磁带玩法依次通过导轮。
- 共享钱包用茵菲谷的 X.F 与 X.record。未付费订单不会扣掉付费额度。代表委托可给 2–3 币。工具和陈设使用同一钱包，回收线圈改变扫频的起手组合。
- 合伙同时开一个。每个计划使用预约时写入存档的结果，等 3–4 个游戏日后分开张、打平、亏一部分三种结果。首次成功最多净赚 1 币，之后同主题成功只回本金。
- 普通支线分 11 天开放 18 条。任务地点使用既有地图节点，三条有跨地图步骤，个别步骤隔一天再回访。任务台账、物品和丢丢币整笔结算。

## 接入和验收

`prototype/autumn/v4/neighborhood-data.js` 存对白、玩法单和合伙数据。 `neighborhood.js` 负责地图、存档和任务交付，`repair-games.js` 只负责维修台内小游戏。 `tools/make_season_game_test.py` 把脚本和音乐编进栗尾市网页内测。原创新曲《收工前再试一次》与工作台音效可由 `tools/render_liwei_repair_audio.py` 重渲染。

先运行 `PYTHONPATH=tools python tools/make_demo.py` 和 `PYTHONPATH=tools python tools/make_season_game_test.py`。在 Chromium 运行 `node tools/check_liwei_neighborhood.js` 和 `node tools/check_liwei_v4.js`。
