# 栗尾维修记

主线 S14 完成后，既有存档第一次进入新版时开放《栗尾维修记》。任务卡沿用统一任务面板，使用橙粉渐变、像素工具箱和循环火星。到工人街西侧小屋与阿简碰头，查清失踪的维修桌，修好他的收音机后，由老郑和洗衣铺老板把钥匙、桌子与工具交给玩家。旧版尚未完成的前置任务从新案开头接起，已经开摊的存档保留经营进度。点击小屋即可开摊。来客卡以报修单形式显示物件和顾客原话。街坊来往留在街景内。后院有乔木和灌木，原公厕改为住宅，公厕迁到南边街道。

## 玩法和收支

- 每次接待一位顾客。物品从分路塔防（挂钟和收音机）、线路扫雷、五子棋、车、水路和磁带中匹配一种玩法。旧档中没交付的挂钟与收音机单自动改用塔防，随机种子和交付状态保留。
- 每单开局显示一到三颗星，普通委托按订单种子随机定级。教学固定一星。同一单重试时难度一致。失败后可跳过委托，失败的当局计一次，跳过不另外扣次数，也不发报酬。
- 每个游戏日最多开 20 局。失败重开和退出后重新开局占一次，交货不占次数。到上限提示「今天好像没有顾客了」，次日恢复营业。独立测试档按自己的游戏日和存档计数，点击「直接测试维修台」时首单固定为塔防。
- 分路塔防可装线圈、挡片、冷凝器、穿甲管与蓄电盒。子弹飞到目标时才结算命中。普通单有三波，混入快型和护甲型杂讯，前置教学为两波。线路扫雷首格和周围安全，支持点按切换插旗。五子棋在 9×9 棋盘与街坊对弈。
- 前置任务中的收音机也使用入门塔防。试车通过转动指针做三次校正。漏水玩法旋转管向并试流，磁带玩法依次通过导轮。付费工钱每日结一张。
- 共享钱包用茵菲谷的 X.F 与 X.record。未付费订单不会扣掉付费额度。代表委托可给 2–3 币。工具和陈设使用同一钱包，回收线圈让塔防多 2 格初始电量。
- 合伙同时开一个。每个计划使用预约时写入存档的结果，等 3–4 个游戏日后分开张、打平、亏一部分三种结果。首次成功最多净赚 1 币，之后同主题成功只回本金。
- 普通支线分 11 天开放 18 条。任务地点使用既有地图节点，三条有跨地图步骤，个别步骤隔一天再回访。任务台账、物品和丢丢币整笔结算。

## 接入和验收

`prototype/autumn/v4/neighborhood-data.js` 存对白、玩法单和合伙数据。 `neighborhood.js` 负责地图、存档和任务交付，`repair-games.js` 负责维修小游戏共用流程，`repair-defense.js` 负责塔防波次、移动、子弹与结算。 `tools/make_season_game_test.py` 把脚本和音乐编进栗尾市网页内测。原创新曲《收工前再试一次》与工作台音效可由 `tools/render_liwei_repair_audio.py` 重渲染。

先运行 `PYTHONPATH=tools python tools/make_demo.py` 和 `PYTHONPATH=tools python tools/make_season_game_test.py`。在 Chromium 运行 `node tools/check_liwei_neighborhood.js` 和 `node tools/check_liwei_v4.js`。
