# 电视画面

电视播放 32 段原创像素小动画，每段 8 帧，画面保持电视原生的 24×12 像素；不改变家具大小、节目选择菜单、看电视的时长或需求收益。

内容包括新闻主持、天气、烹饪、访谈；山丘、湖泊、森林、瀑布、沙漠、雪山、花田、海滩；汽车、巴士、火车、帆船、飞机、太空；白天城市、夜景、街道、港口、桥梁；猫、狗、企鹅、鱼群；歌手、舞蹈、足球、网球、热气球。

观看时约每 8–14 秒随机切换。采用洗牌袋，每一轮全部播完后再洗牌，轮次交界不连续重复同一段。动画正常为 6 帧/秒；减少动态模式显示每段的首帧，仍保留节目轮播。播放状态属于临时视觉状态，不进入存档。

## 文件

- `art/src/concept/tv_programs.py`：全部画面和动画，用现有 pixelkit 与调色板绘制。
- `prototype/demo/tv_playback.js`：随机播放，以及屏幕发光画面的前景遮挡。
- `tools/make_demo.py`：打包 256 帧图片和播放脚本。

## 遮挡规则

房屋中的主角、客人、坐姿、睡姿、椅子和前景家具先绘制到 `homeActors`，再与房屋背景一起完成原有光照。电视画面在光照后保持自身亮度，但用同一份前景的透明度扣掉被遮住的像素，最后才合成到房屋。

这解决了原来电视发光画面直接在人物之后覆盖绘制的问题。遮挡使用真实像素轮廓，人物发型之间的透明空隙仍可看见电视，不使用整块矩形挖空。

## 检查

从源码重建预览后运行：

```sh
node tools/check_tv.js http://127.0.0.1:8786/
```

覆盖 32 段/256 帧的尺寸与动画、两轮洗牌、轮次交界防重复、开关/恢复播放、减少动态模式、四档尺寸的实际观看画面，以及 97 项日夜/男女/全部发型/客人的逐像素遮挡检查。另用坐姿、留宿、串门和同行检查，确认共用前景层没有改变其他人物绘制流程。
