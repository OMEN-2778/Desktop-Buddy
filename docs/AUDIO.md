# 游戏声音

设置顺序：时间流速 → 界面大小 → **背景音乐** → **音效** → 置顶游戏 → 存档 → 更新。
两个开关复用现有像素按钮，默认关闭，互不影响；点击立即记住，导出/导入存档也包含 `settings.bgm`、`settings.sfx`。旧存档没有声音字段时默认关闭。浏览器刷新后，已开启的声音会在第一次点击或按键时恢复（浏览器的自动播放要求）。

## 配乐

使用用户原有合成源码重建的 16 首曲目，不改旋律或配器：

- 自己家、朋友家、家门口：四季 × 昼夜八首。6:00–18:00 使用白天版。
- 公园五区域：同一季节共用对应公园曲目，换区域不重启。
- 商场：人潮高光。
- 酒吧：白天杯中日光、夜晚琥珀低音。
- 海边码头：雾港归帆。

按钮、面板、来电等 10 个短音随页面携带，开启后无需另等网络请求；其余音频按需加载。音频地址带内容版本号，刷新新版后不会沿用旧录音缓存。

换曲用 1.2 秒交叉淡化，旧播放器会释放。游戏倍速不改变音频播放速度。手机铃声、机会卡暂停游戏时，配乐不被切断。

## 音效与环境

37 个原创合成音效 + 7 个 CC0 音效的播放副本，共 44 个：

| 用途 | 触发 |
|---|---|
| 界面 | 按钮（含造型室）、需求悬浮展开/收起、人脉入口与面板、设置、日记、情绪、时间提示、气泡菜单、选单、社交弹窗、机会卡及结果、对话出现 |
| 电话 | 循环铃声，接听/拒绝提示；接听或拒绝即停止铃声，始终按真实 6 秒计时 |
| 家具 | 坐下、床铺/毛巾/衣物、门窗、灯开关、冰箱、翻书、键盘、洗澡/洗手、冲水、做饭、餐具、喝饮料、浇花、洗衣机、乐器、电视、电影 |
| 公共场景 | 酒吧调酒、公园日料、商场吃饭/影院/宠物店等；朋友家使用同一套动作声音 |
| 环境 | 晴天鸟鸣、树叶风声、非冬季夜间虫鸣、码头海浪/海鸥、人群低语与偶尔笑声、门口猫叫、雨声、雷声；室内雨雷更轻，商场/酒吧隔绝室外天气声 |
| 来访 | 朋友到家时门铃，野猫事件猫叫 |

动作声音在开始使用物体时触发，不在走向物体时提前触发。持续水声等随动作结束退出；暂停游戏时动作音停止，环境音保留。雷雨户外不播放鸟鸣、人声；下雪也不播鸟虫。界面音有限流，单次音最多 10 个同时播放，BGM 与音效独立输出，0% 使用硬静音。关闭音效立即淡出所有音效通道和待播放任务。页面隐藏时暂停声音，不在后台累积播放。

这版是界面提示音、环境音与动作拟音，不包含对白配音。

## 代码入口与新增规则

- `prototype/demo/audio.js`：两个总线、播放器生命周期、动作/环境适配、界面状态观察。音频时钟使用 Web Audio / 实际时间，不能使用 `sim.t` 安排铃声、重复播放或声音速度。
- 原有按钮走统一点击音；新增悬浮面板/弹窗加入 `installUI()` 的逻辑状态观察清单，不能按逐帧动画或鼠标移动重复发声。
- 新增动作补充 `ACTION_SOUND` / `ACTION_LOOP` / `ACTION_REPEAT`；场景特例在 `activity()` 适配，避免在绘制函数里调用声音。
- 瞬时事件用 `gameAudio.sound(id, volume, {gap})`；雷电和电话有明确生命周期入口。
- `tools/make_demo.py` 自动复制音频到原始预览的 `audio/`；`desktop/scripts/copy-web.mjs` 将同一资产复制到 Pages 和未来桌面包的 `dist/audio/`，无需运行时连接第三方录音网站。

## 资产与重建

已入库可播放 MP3，不需要每次页面构建重新合成。原始曲目和环境录音保存在 `AUDIO_LIBRARY/BGM`、`AUDIO_LIBRARY/SFX`。`SFX/game` 是 37 个原创合成声音；`SFX/processed` 是 7 个裁剪、平衡音量、处理接缝的 CC0 播放副本。

完整重建（需 numpy/scipy/ffmpeg/curl）：

```bash
python3 AUDIO_LIBRARY/tools/build_audio.py
```

单独更新新增音效或录音播放副本：

```bash
python3 AUDIO_LIBRARY/tools/build_game_sfx.py
python3 AUDIO_LIBRARY/tools/prepare_game_samples.py
```

授权与原作者见 `AUDIO_LIBRARY/docs/LICENSES.md`，合成音效和录音裁剪参数分别见 `GAME_SFX.json` / `PLAYBACK_SAMPLES.json`。

## 音量滑条与实录更新

背景音乐与音效改为独立的 0–100% 像素滑条，0% 静音，初始都是 0%。`bgmVolume` / `sfxVolume` 保存到设置与存档；旧开关为开时迁移为 60%，关时为 0%。支持拖动、点击轨道及键盘调整，两条滑条和数值列严格对齐。

公园的风声、树叶和鸟鸣均改用 CC0 实录，不再播放合成树叶/风/虫鸣。流水、冲水、做饭、倒水、浇水、翻书、键盘、餐具、喝饮料使用 CC0 实录副本；后续扩展又补齐了衣料、门和椅子等实录；界面提示、铃声和情绪旋律为原创电子音。后续优先选用授权清楚的实录生活素材。

水声与做饭不再同时触发单次和循环两路，冲水声降低。全部脚步声取消。实录源和处理参数分别见 `REAL_FOLEY_SOURCES.json`、`PLAYBACK_SAMPLES.json`。

滑条与迁移验证：`node tools/check_audio_volume.js`。

## 环境层与声源布局

`prototype/demo/audio_scene.js` 负责场景声源，`audioSpatial()` 依据主角与声源的距离衰减，并按画面位置设置左右声像；不同房间之间进一步降低音量并加低通。自己家和朋友家分别使用自己的房间标识，避免重复角色名的房间串音。

关窗和拉窗帘时，外面的雨声更轻、更闷；开窗能听清些，干燥白天还能听见室外鸟鸣。商场、酒吧、放映厅和公园厕所隔绝外部环境。公园湖区增加靠近湖边才听清的拍水声，凉亭偶尔轻微木响，樱花摊的汤锅和餐具声有距离衰减；码头使用实录海浪、海鸥、船体和远处汽笛；酒吧增加冰块、摇酒器、杯子与轻声交谈。商场自动门、偶尔收银提示和餐厅厨房与影院环境分别处理。家里与朋友家增加门、衣物、椅子、杯子、冰箱等实录动作，继续不播放脚步。

音乐、环境、动作和界面分层输出，保留轻铃声和柔和情绪提示。已取消所有自动音量避让与共用压缩器，铃声、对话、电视、电影和情绪音不会压低 BGM 或雨声。环境只因场景、天气、距离及窗户状态发生自然变化；鸟鸣、远处汽笛和杯子声留出间歇。主角每句话不再都发提示音，对方对话只作低频轻提示。

验证：`node tools/check_audio_layers.js`、`node tools/check_audio_volume.js`。

## 情绪短旋律

16 种主情绪各有独立的 2–5 音原创短旋律，另有一段很轻的入睡过渡，共 17 段，约 1–2 秒。使用电钢琴、木琴、钟、拨弦、木管/弦乐/铜管的原创合成音色，部分配低鼓；不使用模拟人生或其他商业游戏录音。旋律、音色、节奏及设计理由记录在 `AUDIO_LIBRARY/docs/EMOTION_CUES.json`，可用 `python3 AUDIO_LIBRARY/tools/build_emotion_cues.py` 重建。

只监听主情绪类型，叠加同类心情或改变分值不重复响；约 0.35 秒稳定后发声，快速连续变化合并为最终情绪，切换时收掉上一段。初始化、读档及从静音恢复不补播旧情绪。来电优先，铃声期间暂缓旋律。音效滑条为 0 时全部静音，入睡旋律额外减轻。短旋律随页面携带，开启音效后就地解码。

验证：`node tools/check_emotion_audio.js`。

## BGM 连贯性修正

BGM 不再随来电、对话、电视、影院、机会卡和情绪短旋律自动改变音量，也不与音效共用压缩器。音乐只跟随自己的滑条及场景换曲交叉渐变；环境与动作层继续避让。此前多个短事件反复压低并恢复音乐，加上音效触发共用压缩器，造成了音乐音量抽动。

## 取消全部自动音量避让

按反馈移除所有事件驱动避让及共用动态压缩器，BGM、雨声、环境与动作声不再因铃声、对话、电影、情绪提示而自动降低或恢复。声源距离、隔墙和窗户状态仍按场景变化。音效末端增加独立二值静音门，0% 立即阻断整个音效输出并取消在播与待播音效；BGM 通道独立。

## 电视声音

电视按当前画面节目选择清楚的节目声：交谈/城市/体育用授权人群实录，烹饪用煎炒，湖海/自然用水声和鸟鸣，音乐类用原创短音乐。声音来自电视所在位置，并遵守音效音量与 0% 硬静音；不改变 BGM。只要电视画面还在播放，暂停游戏时间不会单独把电视声音关掉，结束观看后停止。没有采样真实商业电视广播。
