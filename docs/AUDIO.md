# 游戏声音

设置顺序：时间流速 → 界面大小 → **背景音乐** → **音效** → 置顶游戏 → 存档 → 更新。
两个开关复用现有像素按钮，默认关闭，互不影响；点击立即记住，导出/导入存档也包含 `settings.bgm`、`settings.sfx`。旧存档没有声音字段时默认关闭。浏览器刷新后，已开启的声音会在第一次点击或按键时恢复（浏览器的自动播放要求）。

## 配乐

使用用户原有合成源码重建的 16 首曲目，不改旋律或配器：

- 自己家、朋友家、家门口：四季 × 昼夜八首。6:00–18:00 使用白天版。
- 公园五区域：同一季节共用对应公园曲目，换区域不重启。
- 商场：人潮高光。
- 酒吧：白天杯中日光、夜晚琥珀低音。
- 海边码头：雾港归帆。

按钮、面板、来电等 10 个短音随页面携带，开启后无需另等网络请求；其余音频按需加载。音频地址带内容版本号，刷新新版后不会沿用旧录音缓存。

换曲用 1.2 秒交叉淡化，旧播放器会释放。游戏倍速不改变音频播放速度。手机铃声、机会卡暂停游戏时，配乐不被切断。

## 音效与环境

37 个原创合成音效 + 7 个 CC0 音效的播放副本，共 44 个：

| 用途 | 触发 |
|---|---|
| 界面 | 按钮（含造型室）、需求悬浮展开/收起、人脉入口与面板、设置、日记、情绪、时间提示、气泡菜单、选单、社交弹窗、机会卡及结果、对话出现 |
| 电话 | 循环铃声，接听/拒绝提示；接听或拒绝即停止铃声，始终按真实 6 秒计时 |
| 家具 | 走路、坐下、床铺/毛巾/衣物、门窗、灯开关、冰箱、翻书、键盘、洗澡/洗手、冲水、做饭、餐具、喝饮料、浇花、洗衣机、乐器、电视、电影 |
| 公共场景 | 酒吧调酒、公园日料、商场吃饭/影院/宠物店等；朋友家使用同一套动作声音 |
| 环境 | 晴天鸟鸣、树叶风声、非冬季夜间虫鸣、码头海浪/海鸥、人群低语与偶尔笑声、门口猫叫、雨声、雷声；室内雨雷更轻，商场/酒吧隔绝室外天气声 |
| 来访 | 朋友到家时门铃，野猫事件猫叫 |

动作声音在开始使用物体时触发，不在走向物体时提前触发。持续水声等随动作结束退出；暂停游戏时动作音停止，环境音保留。雷雨户外不播放鸟鸣、人声；下雪也不播鸟虫。界面音有限流，单次音最多 10 个同时播放，最终输出带动态压缩。关闭音效立即淡出所有音效通道和待播放任务。页面隐藏时暂停声音，不在后台累积播放。

这版是界面提示音、环境音与动作拟音，不包含对白配音。

## 代码入口与新增规则

- `prototype/demo/audio.js`：两个总线、播放器生命周期、动作/环境适配、界面状态观察。音频时钟使用 Web Audio / 实际时间，不能使用 `sim.t` 安排铃声、重复播放或声音速度。
- 原有按钮走统一点击音；新增悬浮面板/弹窗加入 `installUI()` 的逻辑状态观察清单，不能按逐帧动画或鼠标移动重复发声。
- 新增动作补充 `ACTION_SOUND` / `ACTION_LOOP` / `ACTION_REPEAT`；场景特例在 `activity()` 适配，避免在绘制函数里调用声音。
- 瞬时事件用 `gameAudio.sound(id, volume, {gap})`；雷电和电话有明确生命周期入口。
- `tools/make_demo.py` 自动复制音频到原始预览的 `audio/`；`desktop/scripts/copy-web.mjs` 将同一资产复制到 Pages 和未来桌面包的 `dist/audio/`，无需运行时连接第三方录音网站。

## 资产与重建

已入库可播放 MP3，不需要每次页面构建重新合成。原始曲目和环境录音保存在 `AUDIO_LIBRARY/BGM`、`AUDIO_LIBRARY/SFX`。`SFX/game` 是 37 个原创合成声音；`SFX/processed` 是 7 个裁剪、平衡音量、处理接缝的 CC0 播放副本。

完整重建（需 numpy/scipy/ffmpeg/curl）：

```bash
python3 AUDIO_LIBRARY/tools/build_audio.py
```

单独更新新增音效或录音播放副本：

```bash
python3 AUDIO_LIBRARY/tools/build_game_sfx.py
python3 AUDIO_LIBRARY/tools/prepare_game_samples.py
```

授权与原作者见 `AUDIO_LIBRARY/docs/LICENSES.md`，合成音效和录音裁剪参数分别见 `GAME_SFX.json` / `PLAYBACK_SAMPLES.json`。
