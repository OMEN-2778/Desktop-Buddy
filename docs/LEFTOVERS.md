# 餐桌剩饭

主角家的一盘饭记录做好时的游戏分钟、整份进食时间、剩余进食时间和每分钟营养。手动离开、如厕打断、存档重开均保留这些字段；返回餐桌不会重新获得一整份营养。完成前不结算菜品情绪和额外奖励。

饭始终使用原来的外观，不随进度缩小；点击有饭的餐桌直接续吃。自主决定吃饭时优先吃现有的一盘。吃完剩饭后饱腹值小于 50 则继续做饭，等于 50 不触发。饭从做好起保留 1440 个游戏分钟，关闭游戏不计时。

数据继续保存在 `sim.meal`，兼容旧存档；旧版正在吃饭的记录依据原结束时间恢复剩余时间。朋友家的餐点由独立的做客系统管理。

验证：`node tools/check_leftovers.js`，包括场景显示、中断、如厕、营养总量、点击餐桌、存档恢复、阈值和过期。
